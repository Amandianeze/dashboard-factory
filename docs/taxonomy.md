# Taxonomy: two ladders, one catalog

Every reusable part of the system is one **catalog item**. It sits on the UI ladder (Brad Frost,
_Atomic Design_) and, where it means something in analytics, on the BI ladder (SQLBI, _Atomic
Design in report and model development_). The source is the front matter of `docs/lld/<id>.md`;
`npm run catalog:build` generates `catalog.json`, the dashboard `kind` enum and the tables below.

## Placement rules

**UI ladder (`atomicLevel`)**

- **Atom:** can't be broken down and still be useful (Button, Formatted value).
- **Molecule:** a small group doing one job (Field = label + input + help + error).
- **Organism:** a distinct section of an interface. Organisms may contain organisms: a Chart panel
  hosts the Ranked bars chart.
- **Template:** page structure with placeholder regions and no real content.
- **Page:** a template filled with real content. Pages are **not catalog items**: they are the
  dashboard specs and app screens listed under [Pages](#pages). Composition goes down the ladder
  only, and the build checks it.

**BI ladder (`biLevel`)**

- **Object:** one value and how it reads: a formatted figure, a unit, a status badge, a delta.
- **Pattern:** a reusable analytic idea: period comparison, slicer, title band.
- **Visual:** a complete analytic view: KPI card, ranked bars, data table/matrix.
- **Page template / report template:** a page layout (Dashboard template) or a multi-page app.
- `null` means UI only: product chrome (Button, Sidebar) with no BI meaning of its own.

**What is not a catalog item**

- **Measures and formats** (`[Sales]`, `sum(revenue)`, `$,.0f`) are SQLBI objects, but they are
  data, not components. Formats are tokens (`tokens/format.json`) and become the `@factory/format`
  module. Measures belong to the semantic layer on the roadmap. Each gets a package LLD in Phase 4,
  not a catalog entry.
- **Data patterns without UI** (currency conversion, Pareto) are transforms or chart specs. They
  enter the catalog only when they get a reusable visual (e.g. a Pareto chart in the D3 chart registry).
- **Chart chrome** (Legend, Axis) _is_ catalogued, as molecules, even though the chart engine draws
  it. Its implementation is the generated engine theme, not a React component.

**Where this differs from the brief's starter table**

- **Empty state** is a molecule, not an organism: it does one job and has no sub-sections.
- **Sparkline** is an atom (the brief's "sparkline mark"). The KPI card composes it later.
- **Chart panel** also covers Plotly, which is in the repo for dense, zoomable scatter.
- **Dashboard template** uses the 12-column grid (Gate 0, decision 2), not 48 columns.
